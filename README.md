# quantprep

A public, bank-agnostic prep site for **AI / ML Director interviews in Global Markets Quant**.

Open [the site](https://eddydong.github.io/quantprep/). One page: Words (live hover glossary), the typical seat, industry briefing, how you’d start (90 days), a 14-day plan, closed-book drills, a 20-session in-page Python warmup, and four timed technicals (ML, DL/GenAI, an in-page coding lab, a live desk scenario).

This is not a job advert and not tied to one house. Coding runs **in the page** (Python in the browser). Do not open the answer key first.

```bash
python3 tools/build_portal.py
```

Rebuilds `index.html` from the markdown in `pack/`.
